# 🧠 Customer Loyalty Prediction & Segmentation ML Project

## 📌 Project Overview
This project demonstrates a real-world Machine Learning workflow using Python and Scikit-learn.  
It performs:

- Customer Segmentation using K-Means Clustering
- Customer Loyalty Prediction using Classification Models
- Model Evaluation and Comparison
- Model Saving and Deployment Simulation

---

## 🚀 Features

✅ Customer Segmentation using K-Means  
✅ Logistic Regression Loyalty Prediction  
✅ Hyperparameter Tuning  
✅ Model Comparison (KNN & Decision Tree)  
✅ Model Deployment Simulation  
✅ Model Saving using Joblib  

---

## 📊 Dataset Description

The dataset contains customer purchase behavior:

| Feature | Description |
|----------|-------------|
| CustomerID | Unique customer identifier |
| MonthlySpend | Amount spent monthly |
| PurchaseFrequency | Number of purchases per month |
| LoyalCustomer | Target variable (1 = Loyal, 0 = Not Loyal) |

---

## 🤖 Machine Learning Models Used

### 🔹 Clustering
- K-Means Clustering (Customer Segmentation)

### 🔹 Classification
- Logistic Regression
- Tuned Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier

---

## 📈 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

---

## 💾 Model Deployment

The final tuned Logistic Regression model is saved using Joblib and used to predict loyalty for new customers.
